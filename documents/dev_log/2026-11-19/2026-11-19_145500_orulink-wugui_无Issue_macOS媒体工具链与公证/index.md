## 根因与范围

本地初次全量测试误扫描 App 子模块的 iOS Pods；按父仓库 CI 范围排除 VINote-app。随后完整后端 5127 通过、9 失败、7 跳过，失败集中于 FFmpeg 8.0.1 Opus EOF 空缓冲区误报。官方 FFmpeg 提交 618fc15e65f57c9ce25d4562f4b516129815608c 说明并修复此问题。8.1.3 工具链实测原失败用例通过。保留严格 stderr、包哈希、原件不可变、尾部 seek 和原文件导出校验；不关闭解析或忽略错误。

## 变更与 TDD

冻结后端 --smoke-test 增加独立合成 WebM/Opus 的真实播放衍生文件验证，避免仅版本横幅通过后带入不兼容工具链。辅助函数只用临时合成音频，不调用模型、账号或外部服务。新增回归先因缺少入口失败，完成后与真实媒体集成合计 19 通过、3 项可选用例跳过。修复的 8.1.3 通过先前所有媒体失败用例。

文档同步 FFmpeg 选择、本地父仓库测试范围和 App/DMG 公证、staple、Gatekeeper、OTA 重新签名的要求。当前完整后端回归、冻结包重建、Apple 公证与发布资产替换仍独立进行，不提前宣称完成。无额外重构；不包含密钥和运行日志。

完整本地后端回归：5137 通过、7 跳过、19 个 subtest 通过。重建后发现 Tauri 只重签顶层应用，PyInstaller 内部二进制仍为 ad-hoc，虽然 codesign --verify 可通过，但不满足公证身份要求。继续补齐发布用嵌套 Developer ID 签名，不把有效签名与可公证签名混为一谈。

## 嵌套签名修复与验证

新增 macos-sign.mjs，按 Mach-O 文件头枚举真实文件，跳过别名和非原生文件；限制四个并发签名，等待整批结束，只对时间戳服务暂不可用有限重试。先签二进制，再后序签嵌套容器，最后验证最终封装；不能在其他资源仍变化时验证主程序的整包 seal。build-desktop 在正式 macOS 的冻结冒烟之前使用此流程。

签名枚举测试先因缺少模块失败；加入实现后发布脚本共 27 项通过。实际重建 App 的 174 个 Mach-O 全部使用 Developer ID Application 完成签名，整体 codesign --verify --deep --strict 通过。仅使用包内 bin 的严格 WebM 预览检查通过；PATH 只含系统目录的冻结后端 --smoke-test 也通过。公证、票据和安装包发布仍在进行，不将有效代码签名当作 Apple Accepted。

本次 v0.3.11 运行时代码仍从既有标签对应 fc3adda 干净构建，使用 FFmpeg/FFprobe 8.1.3 替换第三方构建依赖并补齐分发签名；新工具链冒烟与签名流程作为后续发布保障合入 dev，不重写已发布标签。
