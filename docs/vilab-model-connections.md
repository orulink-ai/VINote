# VINote 固定公网模型服务

当前产品约定（2026-11-03）取代旧版本的外部连接和本地会议模型方案。VINote 模型服务固定为 `https://api-hk.orulink.ai`；产品启动、开发、打包均不提供地址编辑或切换，环境变量不能覆盖该 Origin。历史连接字段不授予改用其他地址或凭据的权限。

## 会议执行边界

会议新处理、重试及重新识别只接受固定公网模型快照。后端在保存新快照和执行前检查会议能力；实际 ASR 分派再次检查能力，不允许退回实时流式识别。本地或自定义配置不能绕过校验。非会议内部处理保持原有行为。

会议 ASR 必须声明 meeting 用途、asr-recording 协议、public 音频交付、WAV、整段 single_request/provider_model 规则、说话人分离、发言时间戳以及有效时长和大小上限。默认模型也必须通过这些检查；缺少会议模型时提示用户明确选择或联系管理员，不选第一个模型、不静默替换为实时模型。

前端上传携带已确认的 ASR/LLM ID，后端冻结该模型对；预检后全局偏好变化不能替换本次选择。默认值读取绑定捕获的服务快照，只补缺失选择。仅总结复用已有转写，检查公网 LLM，不要求原 ASR 仍可用，不调用 ASR。

## 旧配置与历史任务

设置 GET 对旧 local 偏好只投影为空模型的公网配置，不修改数据库或选择默认模型。用户在设置明确选择并保存后，现有 PUT config 将偏好迁移为 cloud。旧任务快照不迁移、不重写；旧本地任务如需重新处理，须从原件另建明确确认的公网操作。

历史任务、回执及已有快照的恢复信息 GET 不因实时模型目录不可达而拒绝读取。需要展示新的可确认模型时可以读取目录，但这不授权执行。未知结果仅恢复原回执，不自动重放。

## 验证

`test_meeting_model_boundary.py` 覆盖本地拒绝、实时及默认模型拒绝、固定快照、仅总结、旧配置显式迁移和 ASR 分派前阻断；模型快照、会议版本与前端上传测试覆盖恢复和选择传递。离线测试不代表公网部署或真实录音推理已验收。
