# VINote 一级与二级导航定稿

2026-10-11：按用户最终方向整理。本文是导航与页面归属契约，不是全部功能已完成的验收报告；替代 navigation-containers-replan.md 中早期的“内容／项目／我的”和“记录／笔记／助手／任务”主导航提案。

## 一级区域与二级分类

| 一级区域 | 二级分类 | 页面责任 | 主操作 |
| --- | --- | --- | --- |
| 会议与笔记 | 会议 | 会议记录、纪要状态、最近更新；点击进入同一会议详情 | 录制会议：准备时选择录音或录屏 |
| 会议与笔记 | 笔记 | 自己写的笔记及链接、文件整理结果；项目与标签筛选 | 写笔记；链接或文件转笔记（两个直接可见的入口） |
| 文件库 | 全部、录音、录屏、视频、其他文件 | 来源设备、大小、位置、播放／预览、关联会议与笔记、导出和删除 | 导入文件：先保存，再选择是否整理 |
| 插件 | 飞书 | 连接状态、授权、默认文档位置、可用权限、默认通知目标、自动交付规则 | 连接／管理飞书 |
| 插件 | MCP 工具 | 已连接服务、可用工具、逐项授权、连接检查、执行结果 | 添加连接／管理连接 |
| 设置 | 外观与语言 | 主题、语言、字号与减少动效 | 选择偏好 |
| 设置 | 录制 | 当前设备的默认录制行为、设备检查、后台／退出行为 | 调整录制偏好 |
| 设置 | 转写与总结 | 服务与模型、默认输出要求、图表和视频关键截图策略 | 保存下次处理使用的默认值 |
| 设置 | 存储与同步 | 本地保存位置、容量、云端状态、待同步、冲突与恢复 | 修改位置／同步／处理冲突 |
| 设置 | 隐私 | 原始媒体上传规则、处理时数据发送说明、插件授权与诊断偏好 | 管理隐私默认值 |
| 设置 | 关于 | 版本、更新、帮助、诊断与许可证 | 检查更新／查看帮助 |
| 账号（头像） | 个人资料、账号安全、登录设备、退出此设备 | 身份、密码与登录安全、会话管理；团队成员为账号下的协作管理 | 管理账号／退出当前设备 |

账号安全、登录设备管理、目录迁移及隐私偏好尚需实现和验收。不能用登录事件列表冒充可撤销的在线会话，也不能把原始媒体已留本地写成完全不向转写服务发送音频。

## 两端展开方式

桌面侧栏：会议与笔记作为明确分组，下列会议、笔记；文件库、插件是独立主入口。设置放底部，账号放头像菜单。文件类型在文件库页内切换，飞书与 MCP 在插件页内选择，不把所有二级项一起塞进侧栏。

App 底栏只有会议与笔记、文件库、插件。会议与笔记页顶端切换会议／笔记；文件库顶端筛选来源类型；插件页列飞书与 MCP 工具。头像打开账号入口并提供设置入口。详情、编辑、导入、录制准备及插件配置是流程页面，隐藏底栏并显示明确返回。

顶部只放当前页面标题／返回和必要的状态。全局查找只有一个入口；页面内搜索明确写“搜索会议”“搜索笔记”或“搜索文件”，搜索对象不同，不共享输入值。任务状态以单一状态入口进入任务与恢复，不占一级分类，也不藏在账号身份操作之中。

## 同一功能只保留一个管理位置

- 不新增“插件管理”二级页：插件页就是目录，MCP 工具页管理连接、工具权限和运行记录。避免“插件管理”和“MCP 工具”进入同一页却被当成两类。
- 飞书连接配置归插件／飞书；设置不再提供第二套授权表单。会议和笔记详情的“分享到飞书”只负责本次交付，可引导连接后返回原交付草稿。
- 默认飞书位置、通知目标与自动规则在飞书配置中维护。本次交付在一个流程中选择已保存版本、个人／组织目录、阅读权限及联系人／群；发布前确认，先创建文档、再设权限、最后发消息。失败只恢复失败步骤；未知消息结果先核验。
- 正文默认 Markdown；查看、编辑、全部版本、逐字稿、说话人、引用截图和图表均属于内容详情。转飞书文档从详情“分享与导出”进入，不另设“格式转换库”。
- 文件库不设“笔记”分类。导入的 MD/TXT 是其他文件，其整理结果在笔记，两者互相链接。导入文件是采集动作，文件库是保留与管理源文件的地方。
- 笔记列表直接显示“写笔记”和“链接或文件转笔记”。后者在同一流程中切换视频链接与本地文件，不需先进入文件库。支持公开视频链接（包括 B 站分享文字）、音视频、TXT、MD、SRT、VTT、JSON；普通网页文章、登录文档和 PDF/Word 的正文提取尚未接通，不以统一“网站／文件”文案暗示已经支持。
- 会议页只接收录制或明确选择的会议文件，笔记页按整理目的生成总结笔记，不以音视频扩展名自动归为会议。App 从笔记入口选音频时保存在文件库，不创建会议录音记录。
- App 接收任务编号后持久保存，返回再进入查询同一任务；查询失败可重新查询，处理可恢复时重试原任务。提交结果未知不自动重发。处理完成先保存笔记，再清理入口草稿；保存失败保留任务编号。
- 存储与同步仅在设置管理，侧栏不另设重复入口。
- 会议页的录音／录屏是录制方式，不是两套纪要列表。应用录屏与外部导入视频按来源排他分类；全部只是汇总视图。
- 项目、标签、归档及回收站在会议与笔记内部组织内容，不另起一级目录。删除内容同步回收站标记；删除来源设备文件独立确认，不删除纪要。

## 页面分区与返回规则

| 页面 | 主要分区 | 返回关系 |
| --- | --- | --- |
| 会议／笔记列表 | 标题与单一主动作 → 搜索筛选 → 状态反馈 → 内容列表 | 顶级页面无需伪造上级；打开详情保留筛选与滚动位置 |
| 内容详情 | 返回与标题 → 当前版本／操作 → 正文／逐字稿 → 按需来源与版本抽屉 → 媒体控制 | 返回实际来源：会议、笔记、项目或关联文件 |
| 录制准备与录制 | 返回 → 设备与权限检查 → 音量测试 → 录制控制 → 保存结果 | 退出正在录制必须选择继续、停止并保存或明确丢弃；收起控制器不停止录制 |
| 导入／链接整理 | 返回 → 来源 → 核验与选项 → 保存和处理 → 原任务回执 | 上一步保留输入；取消不冒充成功；未知回执先查询原任务 |
| 文件详情 | 返回 → 文件身份与来源设备 → 播放／预览 → 关联内容 → 导出／删除 | 返回文件库，保留类型筛选；跨设备无原文件时指明来源设备 |
| 飞书／MCP 配置 | 返回插件 → 状态 → 连接／权限 → 默认规则或工具 → 保存结果 | 从内容交付进入时回到交付草稿；直接进入时返回插件 |
| 设置子页 | 返回设置 → 标题 → 同一职责的配置分区 → 保存反馈 | 不跳回无关内容列表；有草稿时先保护 |
| 账号子页 | 返回账号 → 当前身份 → 单项操作 → 反馈 | 退出仅当前设备；有未保存录制先处理，有待同步内容明确保留 |

加载保留标题、返回与可用缓存；错误在失败的分区内说明影响并提供重试；重试保留输入、选中版本和目标；成功以持久保存或服务回执为依据。权限拒绝、格式不支持、未配置服务属于可解决的阻碍，不无限网络重试。

短选项用 Menu／Popover；单次交付用一个 Sheet／Bottom Sheet 内步骤；长配置用页面；删除、断开、丢弃用确认层。关闭顺序是短菜单 → 流程上一步 → 任务弹层 → 页面上级。危险确认可覆盖当前任务，禁止再叠第三个任务弹窗。取消恢复原焦点与上下文。

## 实施验收边界

现有两端已经采用会议与笔记／文件库／插件主结构。本轮将两端目录中的“插件管理”更名为“MCP 工具”，消除同页多名称。本稿列出的账号安全、登录设备、隐私、文件目录修改，以及全部原生失败／重试路径，仍需按功能实际实现验收；不得仅以导航出现或测试通过宣称已完成。
