| 区域 | 页面主体 | 操作及返回原则 |

| 会议与笔记 / 会议 | 会议记录和纪要，录制状态 | 录制会议、导入会议音频；录制停止先保存原件，生成需明确选择。详情返回所属会议视图。 |

| 文件库 | 当前设备的真实原文件 | 信息/播放、关联内容、原件管理分区。原件与正文删除互不替代；来源选择不得打开另一份旧正文。 |
| 插件 | 连接及已授权内容工具 | 飞书作为内置连接；全文中英翻译使用真实 MCP，不混成普通 LLM 按钮。连接、模型、预览、确认、结果和明确保存独立。 |
| 设置与账号 | 偏好、默认行为及账号操作 | 存储与同步仅属设置；任务恢复由状态入口进入；账号从头像进入，保留真实返回来源。 |

## 正常、失败、重试的约束
