# 会议音频预处理：代码审计与验证契约

日期：2026-10-19。状态：只读代码审计及离线方法记录；不是预处理改动、模型效果认证或发布验收。本记录不包含真实会议媒体、文字、人物、区间、测量数据或本机私有产物路径。后端和测试未因本轮审计修改，也未新增 provider 调用。

## 已确认的代码风险

### 预处理配置未绑定说话人缓存身份

`SpeakerDiarizationService._source_signature` 包含原件 hash、模型文件 size/mtime、聚类阈值、请求人数和聚类 revision，但没有预处理版本、滤波参数、声道映射或派生采样表示。缓存另核对 duration；滤波修改后若时长不变，旧 turns 仍可能命中。与此同时，ASR 的规范化 WAV 字节身份可能已改变。由此可出现新声学材料与旧说话人分析混用，这是代码条件支持的风险，不是已证明某个真实任务已命中错误缓存。

建议为新的分析记录加入明确 preprocessing fingerprint，包含实际应用的算法版本、参数、采样格式和声道策略；必要时记录本机解码实现版本/派生字节摘要。保存 applied/bypassed 及旁路原因。历史缺失字段保持未知，不能事后填成已应用。身份变化不能绕过未知 ASR 结果保护，不能自动重跑、替换模型或覆盖已确认回执；执行仍由原有授权/新操作契约控制。

### 弱语音与背景不能靠全局阈值分离

安静、VAD 未检出、说话人占比低、ASR 空文本均不能单独证明无会议内容。反过来，模型检出活动也不证明该段是有效会话。应保留完整声学时间轴、原始文字与回执，不用绝对 dB、全局静音门或说话人占比删除内容。

已确认背景可以作为带来源的内部语义约束，绑定确切 source/task/owner。不得把某个验收样本的偏移硬编码进生产规则。会话级文本跨过背景边界时，不能整窗删掉或伪造词级分割；必须有可靠更细时间或保留边界歧义。同时间段独立可读的会议画面不应一并屏蔽。背景说明、识别缺口及声学诊断留在内部，不生成最终纪要里的技术报告或虚构待办。

### 增益、瞬态和声道策略需要观测

当前链路没有显式全局 AGC。滤波和重采样仍可能改变瞬态峰值；“平均能量下降”不等于“所有采样点衰减”。float 转 s16 的 clip 会限制越界值，需用有界观测量评估实际峰值/饱和比例，不能仅凭滤波名称保证无失真。

后续如有越界证据，先离线比较仅衰减的固定 headroom（gain<=1）与合理限幅方案；不要逐块将安静区自动拉到目标响度。不能因小量瞬态越界认定它就是 ASR 错词根因，也不能无差别加重降噪。多声道/多音轨需要明确源选择与映射策略，避免把默认单声道转码当作已保留所有音轨关系；单声道材料不能验证立体声相消风险。

录制端可为新录音保存受支持的实际 track.getSettings 音频处理字段，不包含设备 ID/label 或其他个人信息；不改旧原件。未取得实际设置前，浏览器/硬件增益状态保留未知，不猜默认值。

## 有界离线验证方法

1. 对同一保留原件顺序运行“仅目标重采样”和“当前完整滤波后重采样”，明确选取音轨。通过 stdout 管道按小块聚合，不加载整场 PCM；限制 worker/线程和运行时间，结果只记数值、版本与身份。
2. 核对样本数、原件 hash/size/mtime、非有限值、峰值、越界计数、短窗 RMS 分布。相同样本数只证明没有时长裁剪，不证明瞬态无延迟。RMS 不是 SNR，不是文字准确率。
3. 合成反例至少覆盖低频 rumble、弱语音/近似语音噪声、轻声主发言与较响背景、爆音、安静中的短有效发言、立体声反相/分离轨道。新方案必须保护轻声，不用总体能量作为唯一通过条件。
4. 现有 [test_audio_preprocessing.py](../../tests/test_audio_preprocessing.py) 覆盖固定正弦组合的低频抑制、时长和原件保持；它不能证明人声保真、背景排除或真实 ASR 改善。冻结期间不修改或重跑测试。
5. 后续若实现缓存身份修复，先写反例：原件不变而预处理配置变化不得读旧 turns；相同配置可复用；历史缺失 fingerprint 不得伪装新策略；未知/已确认 ASR 不得被顺带重放。
6. 后续若实现来源背景注记，验证源/任务/owner 变更失效、跨边界原始窗、背景中有人声、轻声主发言、独立视觉证据保留。注记不改原始音频/ASR，不让诊断污染最终正文。

## 后续实现边界

优先补谱系、缓存身份和有界观测，再依据证据决定是否改变滤波/增益。当前文档只是审计与修复建议，不授权额外模型调用，不代表实现或测试已完成。预处理、说话人、转写编排和录制采集分别由所属模块负责人落地；先形成可审阅补丁，再依现有冻结与执行约束推进。
